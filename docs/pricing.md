# Pricing

ForgeNest offers a free Startup plan for startups at $0 per month, including 1000 API requests per day and 1 project.
The Pro plan costs $49 per month, including 10000 API requests per day and 10 projects.
The Business plan costs $199 per month, including 100000 API requests per day and 50 projects.
Each plan includes API access and webhooks. These fictional prices are in USD.
